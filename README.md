# 智慧桌球教練：教練與學員練習工具

畫面版本 `1.2.0`。依 `TASK-001`、`TASK-003` 架構及 `RESEARCH-002`、`TASK-004` 擴充：第 0 課選拍、五階段共 25 個動作、52 項標準、29 題常見問題與教練確認晉級。採原生瀏覽器模組，無建置流程、無應用套件、無外部字型或追蹤。未設定資料庫時，以本機運作；教學縮圖僅連線 `i.ytimg.com`，影片由使用者點擊後開啟外部頁面。錄影片段不會上傳。

## 本機開啟

在專案根目錄執行：

```powershell
python -m http.server 18761 --bind 127.0.0.1 --directory app
```

開啟 <http://127.0.0.1:18761/#home>，停止時按 `Ctrl+C`。本次環境的 `8061` 拒絕綁定，因此使用 `18761`。請透過靜態伺服器開啟，直接雙擊 `index.html` 無法正常載入模組與離線快取。

同網路的手機可由操作者改用 `--bind 0.0.0.0`，再瀏覽電腦區域網路位址；一般未加密的區網網址不支援相機與安裝式網頁功能。相機與離線安裝需要安全網址或本機環境。應用可放在靜態網站根目錄或子目錄，不需要路由重寫。本次沒有部署。

## 角色與練習流程

1. **選擇角色**：首次選「我是學員」或「我是教練」，設定頁可切換。本機角色區分操作流程，沒有身分認證。
2. **學員練習**：首頁與階段總覽最上方可進入選拍課及動作分類。五題問卷依年齡／手掌、現有球拍、預算、攻守偏好與教練協助提出規格；不推薦品牌、不放購物連結。我的球拍跟著學員檔保存，教練可查看。教學頁依序顯示要領、空拍口令與鏡前檢核、影片、錯誤對策、合格標準、練習入口；教練指導依角色展開或可折疊。
3. **引導練習**：設定每組次數、總組數、休息秒數（預設 30 秒）及每下秒數。可點大按鈕計數，或使用自動節拍；支援暫停、略過休息及全螢幕。中文語音包含「一、二、三」、每五次報數及組間提示，可關閉；不支援語音仍可計數。完成後帶入紀錄表單，再填實際分鐘與穩定度後儲存。
4. **教練管理**：從「管理學員」新增、改名、切換或確認刪除學員，查看階段與練習量，替練習或影片片段寫回饋。至少保留一位學員；刪除會移除該學員本機文字與影片。
5. **指定課表**：教練選日期及已解鎖動作，覆蓋當日推薦。「恢復今日自動推薦」留下可交換的取消標記，避免舊檔把已取消課表帶回。
6. **確認晉級**：每個動作完成指定數量測驗（或空拍全檢核）、教練品質至少 B 與動作確認，階段檢核全部達成後，再由教練確認對話框晉級。學員模式不能評品質或確認。新晉級保存 `standardVersion: 'task004'`；既有歷史晉級保留原練習量規則，不回溯作廢。練滿次數本身不會晉級。

首頁提供連續練習天數、週一至週日的次數／分鐘長條圖與階段完成徽章。今日尚未練習時，可延續截至昨天的連續天數；舊紀錄未填分鐘以零計，不推估時間。「有幫助／沒幫助」分別記在每位學員名下，曾有效的對策優先顯示。

教材、週數、練習量及檢核均為「建議範例，待教練審核」。完成度代表紀錄量，不取代教練觀察，也不代表已學會動作；沒有串接雲端人工智慧或自動姿勢評分。

## 影片回看

- 錄影不收音，每段最長兩分鐘；停止後存入此瀏覽器的 `IndexedDB`，包含學員、動作、日期與備註。**每位學員保留最近 20 段**，新片段會淘汰較舊片段，也可單獨刪除。單一檔案上限 100 MB，仍受剩餘儲存空間限制。
- 支援 `0.25×`、`0.5×`、`1×`、以 `1/30` 秒前進／後退及重複播放。左側學員片段與右側示範可共同播放、暫停及調速；沒有動作時間軸自動對齊。
- 教練仍可設定本機示範檔並排播放；外部連結只接受研究清單已驗證的影片識別碼，網址可用 `youtube.com` 或 `youtu.be`。外部影片以新分頁開啟，不嵌入播放器，也不嘗試並排同步外部影片。舊版任意外部媒體網址安全轉回本機設定，不自動載入。
- 每動作有已驗證教學影片，顯示延遲載入的縮圖、原標題、原頻道與語言。教練可在動作教學頁新增清單內影片或隱藏／重新顯示。影片版權屬原頻道，由教練審核是否適用；不把清單驗證當成授權或教學資格認證。
- 本機片段及示範檔不進雲端，**不包含在學員檔或完整備份**。請另行下載重要錄影片段。不同裝置、瀏覽器與網址來源不共用；清除網站資料、私密瀏覽結束或裝置儲存回收都可能遺失。
- 離線快取只保存應用資產，本機影片由瀏覽器資料庫保留；不快取影片平台或縮圖請求。離線顯示「需要網路才能看影片」。

## 動作測驗與常見問題

從動作教學頁的「記錄動作測驗」進入：成功率逐球點成功／失誤，可復原；連續板數以失誤或結束完成一次、保留最佳與各次；限時計數到時停止，提前停止可保存但不合格；空拍逐項勾選。品質評分為各維度 A／B／C／D，平均至少 B，只有教練模式能填。數量顯示入門／合格／熟練，仍需動作品質與教練確認。測驗存入學員檔、練習紀錄與階段評估，採每動作最新紀錄判斷；重新計數會取消先前確認，學員重測也會清除舊品質分。

目前上桌動作的多個數量標準擇一達到合格；空拍與步法需全檢核。各標準保留 `sourceNote`。全部數字是「建議範例，待教練審核」，並非專業認證量尺。左推右攻、正手兩點以「輪」計，其餘依標準標示計板或球。

底部「常見問題」提供 29 題、5 類問題的關鍵字搜尋與分類篩選，可連到相關動作、影片與標準。找不到答案可送出提問，沿用回饋的 `question` 類型；教練可回答、編輯發布題目、加入常見問題，再編輯或隱藏。學員可查看本機保存或同步回來的回答，教練新增題顯示來源與日期。提問、回答及自訂題目在完整備份中；單一學員檔只含該學員的球拍／測驗等，不含全域問答，離線交換問答請用完整備份。存於本機不代表已傳送給任何人。

清單實際為 41 個不同影片識別碼、48 筆關聯（25 動作共 47 筆、選拍 1 筆），與研究文字寫的「47 支」計數口徑不同；全部以已驗證清單為準。逐動作數量見 [內容核對表](.verification/task004-content-report.md)。

## 舊資料、學員交換與完整備份

文字資料仍沿用 `table-tennis-coach-v1` 儲存鍵。讀到第 1 版內容時，自動轉成第 2 版多學員模型，放入「原有學習紀錄」學員，保留練習、晉級、外觀及使用回饋；選角色後繼續使用。原始內容損壞時停止寫入，不直接覆蓋，可到設定匯出未解析原始資料後處理。

| 操作 | 行為 |
| --- | --- |
| 匯出我的／目前學員檔 | 匯出該學員的球拍、練習、測驗、晉級、回饋、課表及對策，格式為 `table-tennis-student`、版本 `2` |
| 匯入學員檔 | 驗證、確認後依學員編號合併；相同紀錄編號不重複，保留較新的名稱、回饋與課表；同階段保留最初確認時間 |
| 匯出完整備份 | 全部學員、應用設定、提問與答覆、自訂常見問題及示範設定；不含影片檔與登入憑證 |
| 從完整備份還原 | 驗證、確認後取代全部本機文字資料，不合併；接受第 1 版備份 |
| 匯出意見回饋 | 單獨匯出本機使用回饋，供人工交付 |

交換流程為「學員匯出 → 教練匯入 → 教練回饋與安排 → 教練匯出 → 原學員匯入」。教練可將新學員加入名單；學員已有練習或晉級資料時，不可直接匯入不同編號。設定可切換目前本機學員。匯出檔包含姓名與自行填寫的內容，由操作者選擇交付方式。

匯入上限 2 MB，驗證動作、數值、日期、唯一編號、階段順序與晉級當時的達標資料。每位學員最多 10,000 筆練習；每組 1–10,000 次、1–100 組、自評 1–5、分鐘 0–1,440。完整備份還原不會自動替換或清除現有影片，同編號影片仍屬該學員，其他片段需人工處理。「清除所有本機資料」會確認後刪除文字、影片及本機登入狀態，不刪除雲端資料。

## 已有資料庫服務的選用設定

`config.js` 預設兩個值皆空，畫面顯示「雲端同步：未設定」，不連線。兩個值都填妥才啟用 `SupabaseStore`，以原生 `fetch` 呼叫資料與登入介面，**不載入外部套件或內容傳遞網路**。範例在 `config.example.js`。

以下為日後由管理者在**既有服務、既有帳戶**執行的接入步驟。本次沒有建立帳號、專案或服務，也沒有執行雲端遷移與綁定：

1. 核對既有服務與資料保存方式，先審查／套用 `supabase/migrations/0001_init.sql`，再審查／套用 `0002_faq.sql`。後者新增常見問題表、球拍／測驗欄位、提問學員對應及回答欄位，包含逐列權限與觸發器。已有相同資料表時須先處理相容性，不要重複執行初始遷移；依既有環境備份及回復程序操作。本次兩份遷移皆未執行。
2. 使用已存在的教練與學員登入帳戶。管理者確認 `coaches.id` 對應教練的 `auth.users.id`，`students.id` 沿用本機學員檔的 `student.id`，`students.auth_user_id` 綁定學員登入帳戶，`students.coach_id` 綁定其教練。新版教練權限還需由受控管理程序設定 `app_metadata.role='coach'`，不是可自行修改的 `user_metadata`。前端不可調整帳戶與教練歸屬，先綁定，避免兩端使用不同編號建立同一位學員。
3. 將實際開啟位址加入登入返回網址允許清單。本機為 `http://127.0.0.1:18761/`；若在子目錄，填相同路徑。登入信返回原頁，應用從網址片段取得權杖、向服務驗證使用者，再清除該片段。請勿分享或保存登入返回網址。
4. 在 `app/config.js` 填既有專案根網址 `SUPABASE_URL` 與公開金鑰 `SUPABASE_ANON_KEY`。此檔會交付瀏覽器，**不得填 `service_role` 或秘密金鑰**；公開金鑰仍須搭配逐列權限。
5. 重載後到設定，以既有電子郵件取得登入連結。請求使用 `create_user:false`，不自動註冊帳號。登入後按「同步文字資料」才讀取、合併及寫入，沒有背景自動同步。

若學員登入帳戶已綁定另一個雲端學員編號，應用保留原本本機學員，並開啟已綁定的雲端學員；可在設定切換本機名單。兩筆資料不會僅因登入而自動混為同一位。

原六張表另加 `faq_entries`。學員只能存取自己的資料，教練只能存取自己名下學員；品質與動作確認由綁定教練寫入。已發布常見問題供所有登入者讀，只有受管控教練可新增／編輯；隱藏題僅教練可讀。一般回饋仍限本人；提問另允許綁定學員及受指派教練讀，教練只能改答覆欄位，不能改原作者或原文。本機切換角色不增加雲端權限。

提問的 `student_id` 僅依實際可見且屬登入者的學員資料設定；未綁定則保留空值，題目中的本機編號不當成存取權限。教練首次補送離線提問後，學員跨裝置讀回答仍依賴相同學員編號與帳號的正確綁定；不同編號不會自動擴權或合併。同步會拉回回答與常見問題，已同步且沒有本機新修改的題目依遠端可見清單更新，移除已隱藏題；尚未上傳的本機新增或編輯則保留，切換角色不會抹掉。`cloudUpdatedAt` 僅作本機同步版本記號，不寫入資料庫欄位。

同步失敗會保留本機資料並提示原因，教練依階段先寫入練習、再寫入確認，已完成部分可在重試時接續。學員的後續階段紀錄須先由教練同步相應晉級並確認帳號綁定，未完成時會在寫入前拒絕。同步依編號合併，沒有雙向刪除；本機刪除學員、還原備份或清除資料不表示雲端也刪除。影片永不進入請求。

## 意見回饋

每頁右上角及設定頁都有「意見回饋」，提供問題回報、功能建議、教學內容錯誤、提問及選填聯絡方式。自動附上原頁面、版本與有限裝置資訊，不附學員姓名、錄影或登入憑證；提問另保留本機學員編號作對應。說明與聯絡方式由操作者自行填寫。

未設定雲端或尚未登入時存本機，可匯出；已設定且登入時送至 `app_feedback`。發送失敗保留本機副本，可透過手動同步重試。存本機不代表已傳給任何人。
